# Record-Demo skill

A Claude Code skill for recording human-paced MP4 walkthroughs of a UI change,
to attach to a pull request. It covers web apps (headless Playwright) and
Electron desktop apps (Linux runner, macOS window capture).

## Install

Copy `skills/record-demo` into either location:

- `.claude/skills/record-demo` in a project, to share it with that repository
- `~/.claude/skills/record-demo`, to use it in every project

Start with [`skills/record-demo/SKILL.md`](skills/record-demo/SKILL.md).
